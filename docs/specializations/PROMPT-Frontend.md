## Overview

PROMPT-Frontend will be a specialized version of the PROMPT Protocol optimized for frontend-only development, design systems, and UI component libraries.

## Target Domain

- UI component libraries
- Design systems
- Single-page applications (SPAs)
- Static site generators
- Frontend-only projects

## Potential Tech Stack

- **Frameworks:** React, Vue, Svelte, Angular, Solid.js
- **Styling:** Tailwind CSS, CSS Modules, Styled Components, Sass
- **Tools:** Storybook, Vite, Webpack, ESBuild
- **Design:** Figma integration, design tokens
- **Testing:** Vitest, Testing Library, Playwright

## Proposed P.R.O.M.P.T Categories

This is a draft proposal. Categories may differ from Web version:

### P - Performance & Optimization
- Bundle size optimization
- Code splitting strategies
- Asset optimization (images, fonts)
- Runtime performance

### R - Reusability & Composition
- Component composition patterns
- Prop patterns
- Render props and children
- Higher-order components

### O - Output & Design Systems
- Design token usage
- Component API consistency
- Variant patterns
- Theming

### M - Markup & Semantics
- Semantic HTML
- SEO optimization
- Metadata management
- Structured data

### P - Patterns & State
- State management patterns
- Component patterns
- Data fetching
- Form handling

### T - Types & Accessibility
- TypeScript for components
- Accessibility (WCAG AAA)
- ARIA patterns
- Keyboard navigation
