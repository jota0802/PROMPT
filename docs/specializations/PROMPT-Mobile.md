## Overview

PROMPT-Mobile will be a specialized version of the PROMPT Protocol optimized for mobile app development across React Native, Flutter, and native iOS/Android.

## Target Domain

- React Native apps
- Flutter applications
- Native iOS (Swift/SwiftUI)
- Native Android (Kotlin/Compose)
- Cross-platform mobile development

## Potential Tech Stack

- **React Native:** Expo, React Navigation, NativeWind
- **Flutter:** Dart, Flutter widgets, GetX/Riverpod
- **iOS:** Swift, SwiftUI, Combine
- **Android:** Kotlin, Jetpack Compose, Coroutines
- **Backend:** Firebase, Supabase, AWS Amplify

## Proposed P.R.O.M.P.T Categories

This is a draft proposal. Categories may differ from Web version:

### P - Performance & Battery
- App startup time
- Memory management
- Battery optimization
- Network efficiency

### R - Responsiveness & Navigation
- Touch gestures
- Navigation patterns
- Offline-first architecture
- Background tasks

### O - Output & Platform UX
- Platform-specific design (iOS Human Interface, Material Design)
- Native components
- Animations and transitions
- Dark mode

### M - Mobile Data & Storage
- Local storage (AsyncStorage, SQLite)
- Offline sync strategies
- Data persistence
- Cache management

### P - Patterns & Architecture
- MVVM, MVI patterns
- State management (Redux, Zustand, Provider)
- Dependency injection
- Clean architecture

### T - Testing & Platform APIs
- Unit and widget tests
- Platform permissions
- Native module integration
- Biometric authentication
